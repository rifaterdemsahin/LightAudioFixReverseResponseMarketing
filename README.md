# LightAudioFixReverseResponseMarketing

# AI video-production pipeline


## 1. Goal
Turn one long raw video (`{{RAW_VIDEO}}`, language `{{LANG}}`, speakers `{{HOST}}` asks, `{{GUEST}}` answers) into a published package: corrected transcript, subtitles, chapters, a tight edit with animated captions, explainer visuals, cleaned audio, music and sound effects, three A/B thumbnails, platform-specific cuts and copy-paste publishing pages. The whole flow is AI-assisted, scripted, versioned and documented.

## 2. Hard rules (never break)
1. **No media in git.** Raw video, renders, proxy, WAVs stay out (`work/`, `out/`, `*.mp4`, `*.wav`, `public/proxy.mp4`). Code, metadata and small generated images/audio (`public/visuals/*.jpg`, `public/audio/*.mp3`) are committed. The raw file is read in place, never copied in.
2. **No secrets in git.** Keys live only in a git-ignored `.env` (`FAL_KEY=...`). Install `.githooks/pre-commit` that blocks key-like text; run `git config core.hooksPath .githooks`. Never echo a key. A key pasted in chat counts as exposed: rotate it.
3. **Document the rationale** of every step in `docs/DECISIONS.md` (numbered, dated, with the why and what was measured).
4. **Commit and push at every step**, small and one concern each. Pull before pushing if others edit the repo.

## 3. Standing instructions (put in `CLAUDE.md`)
- Keep `README.md` current: emoji style, Mermaid flow diagram, status table, steps table, links at the top (watch link, social posts, live site).
- Always regenerate the timeline (`docs/TIMELINE.md`) when cuts change.
- Always version what is created: `scripts/version.py bump|snapshot`, `CHANGELOG.md`, git tags, `versions/vX.Y.Z/`.
- Always make **three completely different thumbnails** (A/B/C) for A/B testing.
- Keep a checklist page and a production-workflow page in sync with the project.
- Record the user's prompts and stages in `docs/WORKFLOW.md`.
- Show an ETA on long jobs (transcription, renders).
- Preview in Google Chrome; use cost-effective fal.ai models; cache results; log spend.
- Check each platform's duration/size limits before making a version for it; assert them in code.
- Measure, do not guess (loudness, SNR, durations, frame counts). Render stills and look. Proofread every cut join.
- Deploy GitHub Pages after pushes that change `site/` (`gh workflow run static.yml`, watch, then curl for 200).

## 4. Stack
| Need | Tool |
|------|------|
| Transcription | `mlx-whisper` large-v3-turbo (Apple Silicon), word timestamps, in a `.venv` |
| Editing/rendering | Remotion (React), compositions `Highlights`, `Main`, `Combined`, per-platform cuts, Stills for thumbnails |
| Audio/video plumbing | ffmpeg (proxy, denoise, loudnorm, mux chapters + soft subs) |
| Generative assets | fal.ai `fal.run` sync API: `fal-ai/flux/schnell` images, `cassetteai/sound-effects-generator`, `cassetteai/music-generator` |
| Site | Static HTML in `site/` generated by Python, GitHub Pages via Actions workflow |
| Language | Python scripts run as `.venv/bin/python -I scripts/<name>.py`; TypeScript in `src/` |

## 6. Pipeline (run order)
| # | Script | What it does | Key rule |
|---|--------|--------------|----------|
| 01 | `extract_audio.sh` | 16 kHz mono WAV from the raw video | read raw in place |
| 02 | `transcribe.py` | Whisper, word timestamps, **prints ETA** | writes `transcript.raw.json`, never edited |
| 02b | `apply_corrections.py` | Apply `data/corrections.json` rules (`active` flag; unconfirmed rules stay off) | names, products, jargon |
| 03 | `make_subtitles.py` | Readable cues from word timing | glue split tokens like `20-30%` |
| 04 | `make_chapters.py` | AI topic segmentation, anchored to exact phrases | assert phrase unique at word level |
| 05 | `make_proxy.sh` | 720p proxy, hard-linked into `public/` | Remotion ignores symlinks |
| 05b | `clean_audio.py` | highpass, `afftdn` denoise, soft gate, two-pass loudnorm -16 LUFS | no compressor (it cancels denoise); measure speech/noise gap |
| 07 | `plan_cuts.py` | Edit decision list `cuts.json` in source time: tighten pauses, drop pre/post-roll, remove duplicate ideas, hook-first highlights, platform cuts; writes subtitles, chapters, `TIMELINE.md` | frames snapped to 25 fps; keep first fullest statement; assert platform limits |
| 08 | `plan_explainers.py` | Pick concept moments; simple animated graphic vs infographic | phrase-anchored |
| 09 | `generate_visuals.py` | flux/schnell text-free art, cached, cost logged | draw words in Remotion, models garble text |
| 10 | `make_thumbnail.sh` / `12_generate_thumbnail_art.py` | Three different thumbnails | extract frame with ffmpeg, use `Img` |
| 14 | `generate_audio.py` | SFX + music clips, cached, estimated cost logged | levels tuned only in `Sound.tsx` |
| 11 | `make_publish.py` | Title, description (people, event, chapters, links), tags, platform posts | values from `data/links.json` |
| 13 | `build_site.py` | Site pages + `CHECKLIST.md` + `VIDEO_PRODUCTION.md` | edit `site_pages.py` |
| 06 | `render_and_embed.sh highlights\|main\|combined\|platform` | Render, loudness pass -16 LUFS, mux chapters and soft subs | ETA on long renders |

## 7. Edit conventions
- The edit is an **edit decision list**; Remotion plays it back. Change the planner, not the video.
- Anchor everything by exact phrases at word level, asserted unique, so a re-transcription still lines up.
- Duplicate removal: 8-ish documented spans, each proof-read at the join; never repeat a removed idea in a shorter cut.
- Look: white captions with the spoken word in the accent colour (`{{ACCENT}}`, default `#ff2b2b`), left-side explainer panel, footer section bar, zoom (`config.ts`).
- Combined timeline: highlights first, then the main edit, with a bottom bar showing section length.
- Sound: whooshes on chapter cards, pops on reveals, ding/buzz for success/fail, music beds about 14 dB under speech, final loudness pass.

## 8. Deliverables
- Full video (YouTube), Combined with sound (community/Skool), LinkedIn cut (`< {{LINKEDIN_MAX}}` min, default 14:00), X cut (`< 2:15`, closing card links to YouTube).
- Three thumbnails per round; titles, description, tags, pinned comment, social posts.
- Site pages: Overview, YouTube, LinkedIn, X, Costs, Checklist, Workflow, Thumbnails, each with copy buttons.

## 10. Bootstrap prompts (in order)
1. *Plan:* "We are working with `{{RAW_VIDEO}}` (language `{{LANG}}`). Install libraries to transcribe it, then edit with Remotion. Plan subtitles and chapter markers. Document rationale, commit and push every step. No video files in the repo."
2. *Build:* "Install components, transcribe, set up Remotion, keep all code here. Keep a Mermaid flow in README.md up to date. Show ETA when transcribing."
3. *Fix:* "Interviewer is `{{HOST}}`, guest is `{{GUEST}}`. Apply these before/after corrections (unconfirmed stay off)."
4. *Cut:* "Write code that decides cuts for best impact, remove duplicated ideas but keep the meaning, with animated white and accent-colour captions, and always generate a timeline."
5. *Visuals:* "Simple animated graphics on the left, fal.ai infographic for complex ideas, cheap models, never commit my keys."
6. *Combined:* "Highlights first, then main, with a footer showing section length."
7. *Audio:* "Clean background noise (measure it). Add sound effects and music with fal.ai."
8. *Publish:* "Title, description, three different thumbnails, YouTube, LinkedIn and X pages to copy from, GitHub Pages site with costs and checklist pages, README link at the top."
9. *Platform cuts:* "Make a version for `{{PLATFORM}}` under its limit" (check the limit first).
10. *Versioning:* "Version everything, add CLAUDE.md, document published links."

## 11. Gotchas
- Remotion bundler ignores symlinks in `public/`: use a hard link for the proxy.
- `OffthreadVideo startFrom` is ignored in a `Still`: extract the frame with ffmpeg.
- Whisper splits `20-30%`, `desk-based`, `1.30`: matchers skip punctuation-only tokens.
- A compressor lifts pauses and cancels denoise: use a gate.
- Image models invent text: ask for text-free art, reword and regenerate (cheap).
- macOS: BSD `sed -i ''`; zsh does not word-split variables.
- `.gitignore` for `*.mp3` hid generated audio: add `!public/audio/*.mp3`.
- Push-triggered Pages runs failed with no jobs; manual `gh workflow run` worked.
- Check names that Whisper may mishear (venue, product names) against the audio before publishing.

## 12. Definition of done
- [ ] Transcript corrected, subtitles and chapters generated and proof-read
- [ ] Cuts, timeline and platform limits asserted in code
- [ ] Audio measured (about -16 LUFS, peak below -1 dBFS) and listened to once
- [ ] Three thumbnails, title, description, tags, posts ready
- [ ] Renders exported (full, combined with sound, LinkedIn, X)
- [ ] Site deployed (200), README, checklist, workflow, CHANGELOG, tag current
- [ ] No media or keys in git (`git ls-files | grep -Ei 'mp4|wav|\.env'` is empty)
